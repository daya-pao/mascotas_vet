# vetAnimal - Sistema de Registro de Vacunas para Mascotas 🐾

vetAnimal es una aplicación web desarrollada en **Angular** diseñada para facilitar la
gestión y el control del historial de vacunación de mascotas. 
El sistema permite administrar usuarios, mascotas y llevar un seguimiento 
detallado de cada dosis aplicada.

## 🚀 Características actuales
- **Panel de Administración:** Visualización rápida de estadísticas (Usuarios, Mascotas, Controles).
- **Gestión de Usuarios:** Registro y administración de perfiles en el sistema.
- **Control de Vacunas:** Registro eficiente de dosis y fechas.
- **Interfaz Intuitiva:** Diseño limpio enfocado en la experiencia del usuario administrador.

## 🛠️ Tecnologías utilizadas
- **Angular** (Framework principal)
- **TypeScript** (Lógica de programación)
- **HTML5 & CSS3** (Estructura y estilos personalizados)
- **Google Fonts** (Tipografía para una lectura clara)

## ⚙️ Instalación
Si deseas ejecutar este proyecto localmente:

1. **Clona el repositorio:**
   ```bash
   git clone [https://github.com/TU_USUARIO/vetAnimal.git](https://github.com/TU_USUARIO/vetAnimal.git)
    ```
2. **Instala las dependencias:**
     ```bash
      npm install
      ```
3.**Ejecuta el servidor de desarrollo:**
   ```bash
      ng serve
   ```
** Navega a http://localhost:4200/.**
